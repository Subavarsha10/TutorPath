
# TutorPath Mathematics Knowledge Base
## Grade 8–10: Algebra and Linear Equations

### 1. Understanding Algebra

Algebra is a branch of mathematics that uses letters
and symbols to represent unknown numbers.

For example:
2x + 3 = 11

Here:
- x represents an unknown variable.
- 2 is the coefficient of x.
- 3 is a constant.
- 11 is the right-hand side of the equation.

### 2. Basic Algebraic Operations

Like terms are terms that have the same variables
raised to the same powers.

Example:
3x + 2x = 5x

Unlike terms cannot be directly combined.

Example:
3x + 2y cannot be simplified into 5xy.

### 3. Distributive Property

The distributive property states that multiplication
can be distributed over addition or subtraction.

Formula:
a(b + c) = ab + ac

Example:
2(x + 3) = 2x + 6

The number outside the bracket must multiply
every term inside the bracket.

Common misconception:
2(x + 3) = 2x + 3

This is incorrect because the student has not
multiplied 2 by the constant 3.

Correct approach:
2(x + 3)
= 2x + 6

### 4. Solving Linear Equations

A linear equation is an equation in which
the highest power of the variable is 1.

Example:
2x + 4 = 12

Step 1:
Subtract 4 from both sides.

2x = 8

Step 2:
Divide both sides by 2.

x = 4

The solution is x = 4.

### 5. Equality Principle

An equation remains balanced when the same
operation is performed on both sides.

If:
x + 5 = 12

Subtracting 5 from both sides gives:

x + 5 - 5 = 12 - 5

Therefore:
x = 7

Common misconception:
Students sometimes change only one side
of an equation while solving it.

### 6. Fractions in Algebra

Fractions represent parts of a whole.

For example:
1/2 + 1/4 = 3/4

To add fractions with different denominators,
find a common denominator.

For algebraic fractions:

x/2 + x/4

The common denominator is 4.

Therefore:
2x/4 + x/4 = 3x/4

Common misconception:
Adding the numerators and denominators
directly is incorrect.

For example:
1/2 + 1/4 is NOT 2/6.

### 7. Common Mathematical Misconceptions

Misconception 1: Incomplete distribution

Incorrect:
3(x + 2) = 3x + 2

Correct:
3(x + 2) = 3x + 6

Misconception 2: Incorrect equality operations

A student changes one side of an equation
without applying the same operation to the other.

Misconception 3: Combining unlike terms

Incorrect:
2x + 3y = 5xy

Correct:
2x + 3y remains unchanged.

Misconception 4: Incorrect fraction addition

Incorrect:
1/2 + 1/3 = 2/5

Correct:
1/2 + 1/3 = 5/6

### 8. Learning Guidance

Students should:
- Understand the meaning of variables.
- Identify coefficients and constants.
- Learn the distributive property.
- Maintain equality on both sides.
- Practise simplifying expressions.
- Verify their answers through substitution.

A tutor should encourage students to explain
their reasoning instead of memorising procedures.
